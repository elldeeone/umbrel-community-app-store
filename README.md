# Luke's Umbrel Community App Store

This is a community-maintained collection of Umbrel apps, curated and maintained by [Luke Dunshea](https://luke.dunshea.au). This app store allows you to install additional applications on your Umbrel node that aren't available in the official Umbrel App Store.

## About

This repository is a fork of the [Umbrel Community App Store Template](https://github.com/getumbrel/umbrel-community-app-store), modified to provide additional applications for the Umbrel community. All apps are maintained on a best-effort basis as a passion project to support the broader Umbrel ecosystem.

## Installation

To add this community app store to your Umbrel:

1. Open your Umbrel UI
2. Navigate to the App Store
3. Click "Add Community App Store"
4. Enter the GitHub URL of this repository
