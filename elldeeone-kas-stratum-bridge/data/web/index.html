Compatible Miners

This bridge has been tested and confirmed working with the following miners:

  • bzminer
  • lolminer
  • srbminer
  • teamreadminer
  • IceRiver ASICs
  • Bitmain ASICs

Both kaspa-only and dual-mining modes are supported for miners that have this capability.
